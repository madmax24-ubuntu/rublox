# Адаптированный промпт для генерации карты 'Rubo Arena' в браузерной игре (Node.js/Three.js)

"Используй предоставленное изображение (image_1.png) как точный образец для генерации полной, детализированной 3D-карты 'Rubo Arena' в нашей игровой среде (на базе Three.js / Node.js). Ты должен воссоздать структуру, стиль и все детали один в один, адаптируя их под нашу систему объектов и материалов.

I. Общая Структура:
Карта представляет собой строго квадратную арену, окруженную прозрачными стеклянными стенами (Mesh/BoxGeometry с материалом Transparent Glass). Вся арена разделена на 4 четких, изолированных биома-квадранта, сходящихся в центре. На углах внешнего ограждения должны быть текстовые индикаторы сторон света (N, E, S, W), реализованные через Sprite или CanvasTexture.

II. Центральная Зона (Рог Изобилия):
В самом центре находится большая круглая платформа (CylinderGeometry/Circle), выложенная мозаикой в виде розы ветров.

    В центре платформы стоит гигантский золотой Рог Изобилия (составной объект из Mesh/Geometry), из которого высыпается груда разноцветных подарков и ресурсов (красные, зеленые, желтые коробки - BoxGeometry).

    Платформа окружена идеально ровным кольцом из 24-х одинаковых миниатюрных фигурок персонажей (маленькие Mesh/Group), стоящих лицом к Рогу Изобилия.

III. Квадранты (По Часовой Стрелке с N):

    Север (N) — Биом 'Лес': Плотный, густой лес из конусообразных зеленых деревьев (ConeGeometry) разной высоты. Внутри леса должны быть две небольшие деревянные хижины (Cabins - составные объекты из Box/Cylinder). Видны редкие розовые цветы (маленькие сферы/диски).

    Восток (E) — Биом 'Крепость-Лабиринт': Сложный, запутанный лабиринт из высоких, толстых стен из серого камня (BoxGeometry с текстурой камня). Лабиринт занимает весь квадрант. Стены имеют зубчатые края (Crenellations). По углам лабиринта и в центре стоят башни. Весь квадрант окружен защитным рвом с темной водой (Plane/Box с материалом Water).

    Юг (S) — Биом 'Арктика': Заснеженная земля (белый материал) с большим ледяным озером в центре. По периметру стоят заснеженные ели и несколько ледяных Иглу (Iglus - полусферы/SphereGeometry). Видны большие скопления синих ледяных кристаллов (кристаллическая геометрия). С одной стороны озера стоит металлическая решетчатая башня.

    Запад (W) — Биом 'Разрушенный Город/Война': Апокалиптический пейзаж. Разрушенные бетонные здания (skeleton buildings - каркасные структуры), разбитые кирпичные стены, колючая проволока. На земле стоят три зеленых военных танка (составные объекты из Box/Cylinder), несколько бронемашин и обломки (crumbled concrete). Вся земля грязная и разрушенная.

IV. Технические Инструкции для реализации в MapGenerator.js:

    Используй существующие классы объектов, материалы и систему мешей нашего проекта. Если объект сложный (танк, рог), создавай его как Group из нескольких примитивов или используй загрузку GLTF/OBJ моделей, если они есть в assets/.

    Соблюдай цветовую палитру: насыщенный зеленый для леса, серый для лабиринта, белый и синий для Арктики, грязный хаки и серый для города.

    Размести все 24 фигурки точно по кругу (используй математику sin/cos в MapGenerator).

    Убедись, что границы между биомами четкие и прямые, но не блокируют проход игрока.

    Соблюдай масштаб: центральная платформа должна быть в 2 раза шире танков, а здания в городе должны быть в 2-3 раза выше деревьев.

Твоя задача — сгенерировать код для `world/MapGenerator.js` (или создать новый модуль генерации), который позволит одной командой инициализировать эту карту в нашем игровом мире."
