# Release Checklist (Yandex Games)

Проект: `Rubo Arena: Голодные игры`

## 1) Название и тексты
- [ ] Название игры в карточке строго: `Rubo Arena: Голодные игры`
- [ ] Такое же название в `index.html` (`<title>`) и на стартовом экране
- [ ] На скриншотах/обложке/иконке нет старых названий (`Rublox`, `RUBLOX`)

## 2) SDK и API (обязательно)
- [ ] Подключен SDK: `https://yandex.ru/games/sdk/v2`
- [ ] Инициализация через `YaGames.init()` выполняется без падения
- [ ] Вызов `LoadingAPI.ready()` есть и реально вызывается
- [ ] Вызовы `GameplayAPI.start()` / `GameplayAPI.stop()` есть (старт/пауза)
- [ ] Автоязык берется из SDK: `ysdk.environment.i18n.lang`
- [ ] Подключено сохранение прогресса через `StorageAPI` (если игра поддерживает сохранения)
- [ ] Проверяется лимит размера сборки (< 50 МБ для бесплатных игр)

## 3) Управление и UX
- [ ] Нет системных горячих клавиш (например `F1`, `Esc` как основная кнопка игры)
- [ ] Пауза на не системной клавише (`M`)
- [ ] На Android/iOS не появляется выделение текста/контекстное меню
- [ ] На мобильном в landscape стартовое меню полностью помещается
- [ ] Поддержка клавиатуры для навигации по UI-элементам (Tab/Enter)

## 4) Геймплей-валидность
- [ ] Матч всегда стартует по кнопке `Начать игру`
- [ ] Не остается в состоянии прототипа/заглушки
- [ ] Нет критических ошибок в консоли при старте раунда

## 5) Медиа-материалы (частая причина отклонения)
- [ ] Обложка и иконка НЕ скриншоты из игры
- [ ] Без рамок и скруглений
- [ ] Хорошее качество, без артефактов сжатия
- [ ] Текст на медиа соответствует языку локали (ru/en)
- [ ] Название на медиа строго совпадает с карточкой

## 6) Возрастной рейтинг
- [ ] Рейтинг выставлен с учетом контента (резкие звуки, хоррор, насилие)
- [ ] Описание не занижает возрастной тег

## 7) Финальная проверка перед отправкой
- [ ] Проверен `single` в чистом браузере (без кэша)
- [ ] Проверен `single` на Android (Chrome/Firefox)
- [ ] Проверен `multi` (если грузишь отдельным черновиком)
- [ ] В карточке описание соответствует реальной механике
- [ ] Нет `console.log` / ошибок в консоли браузера (в продакшене)
- [ ] Проверена загрузка при медленном интернете (>10 сек не блокирует игру)

## 8) Аналитика и обратная связь
- [ ] Подключена Яндекс.Метрика для отслеживания активности игроков
- [ ] В игре есть кнопка «Оценить» / «Написать отзыв», ведущая на карточку игры
- [ ] Реализован механизм обратной связи (форма, email или ссылка на поддержку)

## 9) Юридические требования
- [ ] В описании игры есть ссылки на контакты разработчика/поддержку
- [ ] При наличии персональных данных — ссылка на Политику конфиденциальности
