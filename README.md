# Rubo Arena: Голодные игры

Браузерная PvPvE-игра на `Node.js` и `Three.js` в low-poly стиле: выживание, лут, сужающаяся зона, боты и зомби.

## Запуск локально

1. Установите Node.js 18+.
2. В папке проекта выполните:

```bash
npm install
npm start
```

3. Откройте в браузере:

```text
http://localhost:3001
```

## Режимы сборки

- `single/` — одиночная версия (для публикации как single)
- `multi/` — мультиплеерная версия (для публикации как multi)

Подготовка сборок:

```bash
npm run build:yandex
```

## Управление

### ПК
- `W A S D` — движение
- `Мышь` — обзор
- `ЛКМ` — удар / выстрел
- `Пробел` — прыжок
- `E` — взаимодействие
- `1..9,0` — слоты инвентаря
- `P` — меню перков

### Смартфон
- Левый стик — движение
- Правая зона экрана — обзор
- Кнопки `Прыжок`, `Удар`, `E` — действия

## Ключевые механики

- Случайная генерация карты
- Лут в домах и ангарах
- Сужающаяся зона
- PvPvE: игрок, NPC и зомби
- События матча (день/ночь, погодные эффекты)

## Технические требования

- Современный браузер с поддержкой WebGL2 и ES-модулей
- Интернет для загрузки внешних ресурсов (если используются CDN)

## Важно

Не запускайте игру через `file://` — нужен HTTP-сервер (`npm start`).
