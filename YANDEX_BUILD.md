# Сборка для Яндекс Игр

## Подготовка

1. Установить Node.js и PowerShell.
2. В корне проекта выполнить `npm ci`.

## Сборка

Выполнить:

```powershell
npm run release:yandex
```

Скрипт создаёт папку `yandex-game`, проверяет JavaScript, SDK, порядок Game Ready, стартовые кнопки и структуру архива, затем создаёт `yandex-game.zip` и выводит SHA-256.

В Консоль Яндекс Игр загружается только `yandex-game.zip`. Архив содержит `index.html` в корне и не добавляется в Git.

## Проверка перед модерацией

1. Открыть черновик через кнопку «Дебаг» или добавить `debug-mode=16` к адресу игры.
2. Проверить, что индикатор загрузчика показывает `IT`.
3. Game Ready должен стать зелёным одновременно с появлением доступного меню.
4. После нажатия «Начать игру» индикатор Gameplay должен стать зелёным.
5. При паузе, потере фокуса и рекламе Gameplay должен стать красным, после возврата — зелёным.
